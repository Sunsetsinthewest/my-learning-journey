## 目录结构

```text
.
├── README.md
├── .gitignore
├── cpp/                          所有 C++ 代码
│   └── hello.cpp                 第一个程序
└── notes/                        所有学习笔记
    └── W01-环境与命令行.md
```

- **`cpp/`** —— 存放所有可编译运行的代码，按周建子目录，例如 `cpp/w03/temperature.cpp`
- **`notes/`** —— 存放所有 Markdown 学习笔记，按周命名，例如 `notes/W03-C++基础语法.md`
