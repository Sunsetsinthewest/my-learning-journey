# W06 · 数组与字符串

> 第 6 周零碎笔记 · 2026-11-11

## 循环与区间

- **数字区间**：起始数是 3、总共 10 个数，实际是到 12（因为 3 包含在里面）
- **for 里声明的变量**：循环里定义的变量和外面不互通，需要自己重新定义

## 输出格式

- 输出 `{1，2，3，4，5}` 这种带分隔符的格式：可以新建一个变量判断是不是首项

## 输入

- **`getline(cin, s, 分隔符)`**：第三个参数可以省略。单引号里写什么，就代表读到什么为止
- **再次强调**：`cin >>` 读到空格就结束了

## string 查找与截取

- **`s.find(子串, 起始下标)`**：找子串，第二个参数可以省略（省略就从 0 开始找），返回下标值
- **`s.rfind(...)`**：从右往左找
- **判断有没有**：
  ```cpp
  if (s.find("xyz") == string::npos) {
      cout << "没找到";
  }
  ```
- **`s.substr(起始下标, 长度)`**：前一个是开始的下标，后面是**长度**（不是结束位置）

## 踩过的坑（本周实测）

- **`static_cast<int>(ch)` 不会把负数变正数** —— 中文的 UTF-8 字节 ≥ 128，`char` 是负数，转 `int` 还是负数，`counts[-28]` 就写到数组前面去了。必须用 `static_cast<unsigned char>(ch)`。症状是「程序不崩，但一行都不输出」。
- **`getline` 只调一次只能读一行** —— 读多行必须包进 `while (getline(cin, line))`。
- **输出格式的前导/尾随分隔符不是小事** —— `字符 ' ' : 1` 和 `  1` 是两回事，前者才看得出那是个空格。
- **数组不写 `= {}` 就是垃圾值** —— 统计类程序必须清零。
