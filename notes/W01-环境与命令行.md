## 一、命令速查

### 定位与查看

| 命令 | 作用 |
| --- | --- |
| `pwd` | 打印当前目录的绝对路径 |
| `ls` | 列出当前目录内容 |
| `ls -l` | 详细模式：权限、大小、修改时间 |
| `ls -a` | 显示隐藏文件（`.` 开头的） |
| `ls -la` | 详细 + 隐藏，两个一起用 |
| `ls -lh` | 详细模式，大小用人话显示（KB / MB） |
| `ls 文件夹` | 列出某个子目录的内容 |
| `ls -R` | 递归列出所有层级，能看清整棵树 |

### 切换目录

| 命令 | 作用 |
| --- | --- |
| `cd 文件夹` | 进入当前目录下的子目录 |
| `cd ..` | 返回到上一级目录 |
| `cd ../..` | 返回到上两级目录 |
| `cd ~` | 返回到主目录 |
| `cd` | 不带参数，同样回到主目录 |
| `cd /` | 返回到根目录 |
| `cd -` | 返回到上次待过的目录 |

> 路径带空格时必须加引号，例如 `cd "D:/My Files"`。

### 新建

| 命令 | 作用 |
| --- | --- |
| `mkdir 文件夹` | 建立一个文件夹 |
| `mkdir 文件夹1 文件夹2 文件夹3` | 一次建立多个文件夹 |
| `mkdir -p 文件夹1/文件夹2/文件夹3` | 建立多层嵌套文件夹，父目录自动创建 |
| `touch 文件` | 创建一个空文件 |
| `touch 文件1 文件2 文件3` | 一次创建多个空文件 | 

> 名字带空格同样需要加引号。

### 复制与移动

| 命令 | 作用 |
| --- | --- |
| `cp 文件1 文件2` | 将文件 1 复制为文件 2（原文件保留） |
| `cp -r 文件夹1 文件夹2` | 递归复制整个文件夹 |
| `cp 文件 文件夹/` | 将文件复制到指定文件夹里 |
| `mv a.txt notes/` | 移动：a.txt 从原位置消失，出现在 notes 里 |
| `mv old.txt new.txt` | 改名：同目录下换名字 = 重命名 |
| `mv notes/ docs/` | 整个文件夹挪个位置 |
| `mv *.txt archive/` | 通配符：把所有 .txt 一次性挪过去 |

### 删除

| 命令 | 作用 | 风险 |
| --- | --- | --- |
| `rm a.txt` | 删除一个文件 | 注意 |
| `rm a.txt b.txt` | 删除多个文件 | 注意 |
| `rm *.log` | 按通配符批量删除 | 小心 |
| `rm -r 目录` | 递归删除整个目录及内容 | 危险 |
| `rm -f 文件` | 强制删除，不询问 | 危险 |
| `rm -rf 目录` | 递归 + 强制删除 | 极度危险 |
| `rmdir 空目录` | 只删空目录，更安全 | 推荐 |

> **命令行没有回收站**，`rm` 删掉就真的没了。执行前先 `pwd` 确认位置、`ls` 确认对象。

### 其他常用

| 命令 | 作用 |
| --- | --- |
| `cat 文件名` | 把文件内容直接打印到终端 |
| `clear` | 清屏 |
| `echo "文字" > 文件` | 把一段文字写进文件（`>` 覆盖，`>>` 追加） |
